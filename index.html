  1. OSDI ’26

    USEC: A User-Requirement-Driven Mandatory Access Control Framework for Operating Systems (Operational Systems)

    Yu Jiang, Wenhuan Liu, Fuchen Ma, Yuheng Shen, Yuanliang Chen, Lei Zhang, He Li, Quan Zhang, Chijin Zhou

    Uses resource-centric policy templates, demand-driven permission checks and LSM-compatible interfaces to simplify Linux mandatory access control.通过面向资源的策略模板、按需权限检查与兼容 LSM 的接口，简化 Linux 内核的强制访问控制。

    Read paper阅读论文 ↗

  2. EuroSys ’26

    Fuzzing Enterprise-Grade Blockchain Systems: Industrial Practice and Solutions

    Fuchen Ma, Yuanliang Chen, Zhen Yan, Yuanhang Zhou, Yu Jiang, Mingchao Wan

    Combines hybrid message generation, two-tier parallel fuzzing and log-based oracles to test enterprise blockchain systems.结合主动与被动消息生成、两级并行测试和日志断言，对企业级区块链系统进行测试。

    Read paper阅读论文 ↗Project项目 ↗

  3. S&P ’26

    Camveil: Unveiling Security Camera Vulnerabilities through Multi-Protocol Coordinated Fuzzing

    Fuchen Ma, Yuqiao Yang, Yuanliang Chen, Yanyang Zhao, Ting Chen, Yu Jiang

    Coordinates HTTP, RTSP and ONVIF through a camera status model to find vulnerabilities caused by interactions between protocols.通过摄像头状态模型协调 HTTP、RTSP 和 ONVIF，发现协议交互引起的安全问题。

    Read paper阅读论文 ↗

  4. ASE ’25 · Distinguished Paper Award

    DualFuzz: Detecting Vulnerability in Wi-Fi NICs through Dual-Directional Fuzzing

    Yuanliang Chen, Fuchen Ma, Yanyang Zhao, Yuanyi Li, Yu Jiang

    Models interactions between Wi-Fi transmission and reception, then uses latency feedback to guide coordinated fuzzing.建模 Wi-Fi 网卡发送与接收过程的相互影响，利用时延反馈指导双向协同测试。

    Read paper阅读论文 ↗

  5. USENIX Security ’25

    Finding Metadata Inconsistencies in Distributed File Systems via Cross-Node Operation Modeling

    Fuchen Ma, Yuanliang Chen, Yuanhang Zhou, Zhen Yan, Hao Sun, Yu Jiang

    Models relationships between cross-node file operations and uses temporary inconsistency duration to guide testing.建模跨节点文件操作之间的关系，以临时不一致的持续时间指导测试，发现元数据一致性问题。

    Read paper阅读论文 ↗

  6. S&P ’24

    Chronos: Finding Timeout Bugs in Practical Distributed Systems by Deep-Priority Fuzzing with Transient Delay

    Yuanliang Chen, Fuchen Ma (co-first author), Yuanhang Zhou, Ming Gu, Qing Liao, Yu Jiang

    Combines runtime delay injection, deep-priority search and transient delays to find timeout bugs in distributed systems.结合运行时延迟注入、深度优先级搜索与瞬态延迟，发现分布式系统的超时处理缺陷。
